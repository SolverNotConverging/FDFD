Periodic eigensolver example
============================

Run `diagonal_pencil.py <diagonal_pencil.py>`_ after installing the packages.
This small generalized eigenproblem demonstrates selecting eigenvalues near a
shift and inspecting original-pencil residuals. It normally completes quickly
and needs no viewer or output files.

The expected eigenvalues are 3 and 4. See the
`library guide <../../../doc/libraries/periodic_eigensolver/guide.rst>`_ and
`API reference <../../../doc/libraries/periodic_eigensolver/API_REFERENCE.rst>`_.
This is a matrix example, so a physical mesh dimension does not apply to its name.
